An introduction to locally weighted regression

Fitting a nonparametric curve to a scatterplot by running a fresh weighted regression around every point of interest — the distance metric, four kernels, three ways to write the estimator, and how to tell whether it worked.

Method
Kernel-weighted local regression
Tools
NumPy · SciPy · Matplotlib
Validation
Train–test split against a known signal

The main idea

In locally weighted regression (LWR), a regression is performed around a single point of interest, producing a nonparametric curve through a scatterplot. Trends and associations in real data are generally nonlinear, but they can be interpreted linearly if you only look at a small enough neighbourhood at a time. LWR does exactly that: training data is weighted by each point's distance from the point of interest using a kernel, and a regression is then computed on the weighted points.

The independent observations are the rows of a matrix X, with features in the columns, denoted p. Every row is therefore a vector, and the distance between an observation and the point of interest is measured with a metric. Because observations contain multiple features, we interpret them as vectors in a finite-dimensional Euclidean space:

$$ dist(\vec{v},\vec{w})=\sqrt{(v_1-w_1)^2+(v_2-w_2)^2+...(v_p-w_p)^2}$$ There are n different weight vectors, because there are n observations.

The predictions are a linear combination of the actual observed values of the dependent variable:

$$\large \hat{y} = X(X^TWX)^{-1}(X^TWy)$$

Visual intuition

This illustrates how locally weighted regression is controlled by tau, the bandwidth. When tau is too large or too small, the regression does not fit the data appropriately. Data validation and scatterplots help reveal when the chosen value is not optimal (1). A larger tau produces a smoother curve, which is not always what you want. Different values of tau — along with different kernels, which alter the shape of the curve — are the two levers available for tuning.

Kernel selection

A wide array of kernels support locally weighted regression. The goal when selecting one is a function with a single local maximum that decays away from the centre, so that nearby points dominate the fit and distant ones contribute little or nothing.

Exponential Kernel 01

$$ K(x):= e^{-\frac{|x|^2}{2}}$$

Unlike the three below, the exponential kernel never reaches exactly zero — every point retains some weight, however small. That makes it smooth everywhere, but it also means the fit is never truly local.

Tricubic Kernel 02

$$ K(x):=\begin{cases} (1-|x|^3)^3&if |x|<1\\ 0 & \text{otherwise} \end{cases}$$

Epanechnikov Kernel 03

$$ K(x):=\begin{cases} \frac{3}{4}(1-|x|^2)&if |x|<1 \\ 0 & \text{otherwise} \end{cases}$$

Quartic Kernel 04

$$ K(x):=\begin{cases} \frac{15}{16}(1-|x|^2)^2 &if |x|<1 \\ 0 &\text{otherwise} \end{cases}$$

The kernel function must be vectorized before it is used for LWR. NumPy's functions are already vectorized, so building the kernels out of them avoids that extra step.

When the vector of data is large, the kernel is applied around each point x[i] to produce a full matrix of weights — one weight vector per observation.

Three ways to write the LOWESS function

The LOWESS function is what actually performs the locally weighted regression. Parameters x and y are arrays containing an equal number of elements; each pair x[i], y[i] defines a point in the scatterplot. The function returns the estimated values of y. There are a few ways to approach it.

1. Solving the linear system directly

The most explicit version: assemble the weighted normal equations by hand and solve them at every point.

2. Fitting a weighted linear model

The same idea, delegating the solve to a linear model fit on the weighted design and target.

3. Gramfort's version

Finally, Alex Gramfort's approach, which introduces the hyperparameter f. Here f is a smoothing span, taking the role that tau plays in the previous two functions: each point's bandwidth becomes the distance to its r-th nearest neighbour, where r = ceil(f * n). The outer loop then reweights by delta, shrinking the influence of points with large residuals so that outliers pull the curve less on each successive pass.

Ultimately, different kernels and different values of tau are what produce better estimates — there is no single correct setting, only one that suits the data in front of you.

Validation

To validate the function, use a train–test split, either on generated data or on imported data separated into training and testing sets. Plotting the kernel regression estimates against the true values then shows how effective the regression actually is.

Generating the data yourself is what makes this a real test: because the true signal is known, the estimate can be compared against it directly rather than against noisy observations that already contain the error you are trying to measure.
